# Responsible AI with GitHub Copilot

## Módulo de referência

- https://learn.microsoft.com/pt-br/training/modules/responsible-ai-with-github-copilot/2-manage-ai-risks

## Notas de estudo

### Riscos identificados

- [ ] Alucinações (informações incorretas)
- [ ] Código inseguro
- [ ] Viés e respostas inadequadas
- [ ] Exposição de dados sensíveis

### Mitigações

- [ ] Revisão humana obrigatória
- [ ] Testes e validações antes de produção
- [ ] Política de segurança para prompts e código
- [ ] Uso de fontes confiáveis para conferência
