# Github-IA

Repositório de estudos sobre IA com foco em uso responsável no desenvolvimento de software.

## Curso base

- [Responsible AI with GitHub Copilot (Microsoft Learn)](https://learn.microsoft.com/pt-br/training/modules/responsible-ai-with-github-copilot/2-manage-ai-risks)

## Objetivo

Organizar conteúdos, exercícios e exemplos práticos para consolidar aprendizados sobre:

- riscos no uso de IA generativa;
- revisão humana e validação de saídas;
- segurança, privacidade e conformidade ao usar o Copilot.

## Como usar

1. Consulte `docs/responsible-ai-with-github-copilot.md` para registrar anotações do curso.
2. Resolva práticas em `exercises/`.
3. Guarde exemplos revisados manualmente em `examples/`.

## Princípios de estudo responsável

- Nunca aceitar respostas da IA sem revisão.
- Verificar fatos, código e segurança antes de aplicar.
- Evitar incluir dados sensíveis em prompts.
